# Bank Management System - Oracle Database Project

This project contains the complete relational database design, ER diagram specifications, logical and physical models, and PL/SQL implementation (Procedures, Functions, Cursors, and Triggers) developed for Oracle Database.

## Project Structure
- `schema.sql`: Database table creation statements and primary/foreign key constraints.
- `procedures.sql`: PL/SQL stored procedures for inserting data into tables with exception handling.
- `functions.sql`: Standalone PL/SQL functions.
- `cursors.sql`: Cursor and implicit cursor operations for batch updates.
- `triggers.sql`: Views and `INSTEAD OF` triggers implementation.

Developed as part of database management systems coursework.
